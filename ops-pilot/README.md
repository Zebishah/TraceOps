# OpsPilot

OpsPilot is a multi-tenant agentic incident investigation and resolution platform.

It is designed to investigate operational incidents using company knowledge, live business data, AI agents, human approval, and auditable action execution.

## Project Status

🚧 Active development

## Planned Core Capabilities

- Multi-agent incident investigation
- Investigator and Reviewer/Critic agents
- Retrieval-Augmented Generation (RAG)
- Hybrid retrieval and reranking
- Source citations
- Tenant-isolated vector retrieval
- Tool calling
- Human-in-the-loop approval
- Pause and resume workflows
- Background processing
- MCP integrations
- n8n automation workflows
- Evaluation and observability
- Idempotent and auditable action execution
